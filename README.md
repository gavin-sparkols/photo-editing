# Editable Images

Perform **OCR recognition** on slide- and poster-style images directly in your browser, then **edit text boxes in the original image coordinates**—move, resize, rewrite, align, and multi-select them. Export the results as **JSON**, composited **PNG** files, or **PPTX** presentations. This project is ideal for image-editing workflows that combine a text-removed background with an editable text layer.

## Features

- **Upload and OCR**: Upload multiple images and run PaddleOCR locally to generate layout JSON containing text boxes (`bbox`), recognized text, colors, font sizes, and more.
- **Canvas editing**: Pan and zoom the canvas freely; drag text boxes, resize them from the corners, and double-click to edit. Multi-select boxes with `Ctrl`/`⌘` + click or `Alt` + drag, then change font sizes, align, or delete them in bulk.
- **Background switching**: Edit against the text-removed, inpainted image by default, or use the hidden option to switch back to the original image for reference (see `chkUseFilled` in `index.html`).
- **Export**: Download batch JSON, composited PNG files for each page, or a **PPTX** presentation with one click (`python-pptx` required).
- **Page ordering**: Reorder and navigate pages from the thumbnail strip on the right. You can also **append images** from the page-order panel without clearing existing pages.

## Requirements

- Python **3.9+** (or another version compatible with the current dependencies)
- Sufficient disk space and an internet connection for the initial OCR model download

## Installation

Run the following command from the project root:

```bash
pip install -r requirements.txt
```

The main dependencies include `paddleocr`, `flask`, `opencv-python`, `pillow`, and `python-pptx`. If you only need to run the service and do not need PPT export, you may omit `python-pptx`; however, the **Download PPTX** endpoint will prompt you to install it.

## Running the App

```bash
python3 editor_server.py
```

Then open **http://127.0.0.1:7777/** in your browser.

## Quick Start

1. Click **Select Images** in the left sidebar, then click **Start OCR**.
2. Select a text box on the center canvas and use the top toolbar to adjust its font size or alignment. For a single box, alignment applies to the paragraph when the text box has focus; when only the box itself is selected, alignment positions it horizontally relative to the full image.
3. Use the **Page Order** panel on the right to switch between pages or drag them into a new order. Click **+ Add Images** at the bottom, or drag files into the app, to append and recognize more pages.
4. Use the sidebar to export JSON or PNG files. PPTX export requires `/api/file/...` background paths generated by OCR on the local service.

## API (Local Service)

| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/api/ocr` | Upload an image using the `image` form field. Returns `layout`, `imageUrl`, `filledImageUrl`, and related data. |
| `GET` | `/api/file/<name>` | Retrieve a temporary image from the upload directory. |
| `POST` | `/api/export_pptx` | Accept a JSON body containing `pages`, `background_files`, and other fields expected by the frontend, then return a `.pptx` file. |

## FAQ

- **OCR is slow, especially on the first run**: This is usually caused by model downloads and cold-start initialization and is expected behavior.
- **PPTX export fails**: Make sure `python-pptx` is installed with `pip install python-pptx` and that the images on the page were recognized by the local service rather than loaded only as local blob previews.
